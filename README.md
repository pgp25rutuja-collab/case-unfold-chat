# Case Insight Bot

Build a web app called Case Reasoning Probe for business school students. The student uploads a case study as a PDF, Word or text file. The app reads the whole case, then a chatbot opens with one precise, case specific question that tests critical thinking, such as a tension, a number to interpret, a stakeholder incentive or a hidden assumption. It never gives the answer or says whether the student is right. Each next question is one short question built on the student's last reply, rotating between assumptions, evidence in the case, counterarguments, and what changes if an assumption is wrong. After about 6 to 8 exchanges it closes politely. Use the built-in AI. Add a button to download the transcript. Keep the design clean and simple.
